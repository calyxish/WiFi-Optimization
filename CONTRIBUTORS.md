## How to Contribute

We welcome contributions! Please see the [README](README.md) for guidelines.

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes with clear docstrings and comments
4. Add tests in `tests/test_all.py`
5. Run `pytest tests/ -v` to verify
6. Open a Pull Request
